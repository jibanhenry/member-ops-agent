# 会员运营智能体

面向门店和商家的会员运营助手：读取会员系统的消费记录，自动完成用户画像、生命周期划分、付费预测、流失预警，
按商家自己的运营方法论给出可执行、算得过账的下一步动作，并为导购起草话术、生成支付宝会员触达请求。

- **演示数据**：2018 年全国大学生数学建模竞赛 C 题公开附件（国内一家大型百货商场的会员系统数据），仅用于非商业演示
- **大模型**：魔搭 API-Inference 上的开源模型 Qwen3.8-Flash-Next（备用 DeepSeek）。发送前会把会员卡号换成临时代号，
  并去掉年龄、性别、入会日期等个人字段
- **私有部署**：同一套代码可以接本地开源模型（Ollama + Qwen），会员数据完全不出门店
- **公开演示**：你在页面上新建的活动、修改的任务会在 6 小时内自动恢复

源代码：https://github.com/jibanhenry/member-ops-agent
